# 달빛 윷놀이

노트북 카메라로 던지기 동작을 인식하는 웹 게임입니다. 전통모드는 팔 동작을 시작 신호로 사용하고, 삼손모드는 몸통의 상승 움직임으로 세기를 측정합니다.

## 실행

이 폴더에서 `python -m http.server 8000 --bind 127.0.0.1`을 실행한 뒤 브라우저에서 http://localhost:8000 을 엽니다. 파일을 직접 더블클릭하지 마세요. 종료는 서버 터미널에서 Ctrl+C입니다.

홈에서 전통모드 또는 삼손모드를 선택하세요. 삼손모드는 카메라 켜고 시작하기를 누르고 카메라 접근을 허용하세요. 상체와 손이 보이는 거리에서 손을 허리 아래에 약 0.4초 둔 뒤 위로 올립니다. 인식 → 윷 애니메이션 → 결과 → 기본 10초 뒤 다시 인식 순서로 반복됩니다. 한쪽 팔로도 가능합니다. 전통모드는 동작 또는 버튼으로 던지며 세기와 관계없이 각 윷의 두 면을 50% 확률로 추첨합니다(도/개/걸/윷/모 = 4/6/4/1/1, 총 16가지). 전통모드는 별도로 10% 확률로 낙이 나옵니다. 최종 확률은 낙 10%, 도 22.5%, 개 33.75%, 걸 22.5%, 윷과 모 각각 5.625%입니다.

우측 하단의 처음화면으로 돌아가기는 진행 중 타이머와 카메라를 끄고 홈으로 돌아갑니다. 홈의 모 감도 입력 / 낙 감도 입력에서 숫자를 저장하거나 동작으로 측정할 수 있습니다. 측정은 한 번 던진 후 확인 창에 값을 채워주며 저장을 눌러야 적용됩니다. 기준은 이 브라우저의 로컬 저장소에 보관됩니다. 모 기준은 낙 기준보다 커야 합니다.

우측 하단의 체험 던지기는 모션 측정 없이 임의 결과로 화면 전환을 확인합니다. 결과 화면에서는 같은 버튼이 애니메이션 스킵 / 다음 던지기로 바뀝니다. 종료는 타이머를 해제하고 카메라를 끕니다. 권한 거부, 카메라 연결 실패, 모델 오류가 나면 재시도하거나 체험 던지기로 진행할 수 있습니다.

홈의 결과 화면 자동 복귀 시간에서 1~30초를 저장할 수 있습니다. 애니메이션이 끝나고 결과를 표시한 시점부터 계산하며 기본값은 10초입니다. 두 모드에 모두 적용되고 이 브라우저에 저장됩니다.

## 여러 명이 번갈아 하기

홈의 팀 등록 패널에서 팀 이름을 추가/삭제할 수 있습니다(최대 8팀). 이 목록은 브라우저에 저장됩니다. 팀을 2개 이상 등록하면 진행 화면(모션 인식/결과) 우측 하단에 차례 넘기기 버튼이 나타나며, 누르면 대기 시간과 관계없이 바로 다음 팀 차례로 넘어갑니다. 화면 상단의 라운드 표시에는 현재 차례인 팀 이름이 함께 나옵니다. 같은 화면의 점수판 버튼을 누르면 각 팀의 점수를 입력하거나 −1/+1 버튼으로 조정할 수 있는 창이 뜹니다. 점수는 말판 이동과 별개로 진행자가 직접 기록하는 용도입니다.

## 말판

팀을 1개 이상 등록하면 모션 인식/결과 화면 아래에 말판이 나타납니다. 홈의 말 개수 설정(1~6개, 기본 4개)으로 팀마다 사용할 말의 수를 정하세요. 게임을 시작(전통모드/삼손모드 선택)하면 각 팀의 말이 새로 배치됩니다.

말은 12지신(쥐·소·호랑이·토끼·용·뱀·말·양·원숭이·닭·개·돼지) 이모지로 표시되고 팀마다 다른 색 배지가 붙습니다. 던지기 결과가 나오면(낙과 체험 던지기는 제외) 말판 아래 버튼으로 이동할 말을 고릅니다(움직일 말이 하나뿐이면 자동으로 선택됩니다). 도/개/걸/윷/모는 각각 1~5칸 이동하며, 같은 팀 말이 모이면 한 칸에 함께 표시되고, 상대 팀 말이 있는 칸에 도착하면 그 말을 처음(대기 상태)으로 돌려보내고 한 번 더 던질 수 있습니다. 윷·모가 나와도 한 번 더 던집니다. 모든 말이 20칸을 돌아 출발점에 도착하면 완주입니다.

칸(1~19번, 모서리인 5·10·15번 제외)에는 홈의 말판 이벤트 설정에서 이벤트를 지정할 수 있습니다. 직접 각 칸의 드롭다운으로 고르거나, 자동으로 채우기 버튼으로 비어 있는 칸에 한 칸/두 칸 전진·후퇴, 한 번 더 던지기, 다음 차례 쉬기, 처음으로 중에서 무작위로 채울 수 있습니다. 이벤트는 브라우저에 저장됩니다.

말판은 20칸 바깥 둘레만 사용하는 단순화된 버전입니다. 가운데를 지나는 대각선 지름길은 전통 윷판의 모양을 살리기 위한 장식일 뿐, 실제 이동에는 쓰이지 않습니다.

## 인식 기준과 제한

- 삼손모드는 손을 내리고 몸을 잠깐 멈춘 뒤, 살짝 앉았다가 몸을 위로 튕기면서 손을 어깨 위로 올립니다. 어깨와 골반이 동시에 상승한 거리와 속도만 점수에 반영하며 팔 속도는 점수에 넣지 않습니다. 몸통과 손이 동작 중 화면에서 벗어나지 않도록 카메라를 배치하세요.
- 준비 시 어깨~골반 길이를 고정해 몸의 상승을 정규화합니다. 어깨와 골반 상승 중 작은 값을 사용하므로 어깨만 으쓱하는 동작은 높은 점수를 얻을 수 없습니다. 3프레임 중앙값과 약 0.1~0.24초 속도 구간으로 순간 추적 오차를 줄입니다. 몸통이 보이지 않거나 크기가 크게 변하면 준비 상태로 돌아갑니다.
- 몸통 세기 = (상승거리 × 180 + 상승속도 × 65) × min(1, 상승거리 / 0.25). 기본 낙 기준 35, 모 기준 220이며, 상승거리 0.08 또는 속도 0.18 미만은 낙입니다. 손을 어깨 위로 올리는 던지기 자세도 필요합니다. 팔만 움직이면 몸통 점수는 0입니다.
- 기존 팔 기준 저장값은 유지하되 적용하지 않습니다. 몸통 기준은 별도 저장소 `yut-body-settings-v1`에 저장하므로 홈에서 모/낙 동작을 다시 측정하세요.
- 도/개/걸/윷/모 시작 기준은 낙 기준 + (모 기준 − 낙 기준) × (exp(2i/4) − 1)/(exp(2) − 1), i=0~4입니다. 단계가 올라갈수록 기준 간격이 넓어집니다. 낙 기준 미만은 낙, 모 기준 이상은 모입니다. 게이지의 100%는 모 기준입니다.
- 실제 힘이나 발이 바닥에서 떨어졌는지 측정하는 기능은 아닙니다. 화면 속 몸통 상승을 추정하므로 카메라 자체가 움직이면 영향을 받을 수 있습니다. 카메라 각도, 조명, 프레임률에 따라 기준을 실제 장비에서 조정해야 합니다.
- MediaPipe Pose Landmarker 0.10.21 및 lite 모델을 외부에서 로딩하므로 최초 사용 시 인터넷이 필요합니다. 글꼴도 외부 로딩이며 실패하면 기본 글꼴로 표시됩니다. 영상은 로컬 브라우저에서 처리하며 녹화하거나 업로드하지 않습니다.
- 모션 인식은 약 15회/초로 제한했습니다. GPU 초기화 실패 시 CPU로 재시도합니다.
- 윷 애니메이션은 CSS 연출입니다. 윷 네 개의 평평한 면 수가 도 1 / 개 2 / 걸 3 / 윷 4 / 모 0으로 표시됩니다.

공식 API 참고: https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker/web_js

실제 웹캠 인식 정확도, 다섯 단계의 체감 구분, 노트북 성능은 사용자 장비에서 확인해야 합니다.
